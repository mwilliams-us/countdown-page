Countdown Page

A simple web-based countdown timer created as a personal project to count down to a friend’s move to Missouri.

About

This project was built as a lightweight, custom countdown page and deployed as a live website. It provided an opportunity to practice front-end web development while creating something useful for a real-world occasion.

Features

* Live countdown timer
* Custom page styling
* Responsive web layout
* Custom images and visual elements
* Deployed as a static website using GitHub Pages

Built With

* HTML
* CSS
* JavaScript

Project Structure

countdown-page/
├── css/        # Page styling
├── images/     # Image assets
├── js/         # Countdown functionality
└── index.html  # Main page

Background

This was a small personal project created for fun while developing my web development skills. The countdown marked the anticipated arrival of friends moving to Missouri.

The repository is preserved as part of my development history and as an example of turning a simple idea into a functional, deployed web project.
